## 執行流程

您正在更新位於 `.specify/memory/constitution.md` 的專案章程。這是一個包含方括號佔位符（例如 `[PROJECT_NAME]`、`[PRINCIPLE_1_NAME]`）的範本檔案。您的任務是：(a) 收集/推導具體值，(b) 精確填充範本，(c) 將修改傳播到相關檔案。

請按以下執行流程操作：

1. 載入位於 `.specify/memory/constitution.md` 的現有章程範本
   - 識別所有形如 `[ALL_CAPS_IDENTIFIER]` 的佔位符
   **重要**：使用者可能需要比範本中更多或更少的原則。如果指定了數量，請遵循通用範本結構並相應更新文件

2. 收集/推導佔位符的具體值：
   - 如果使用者輸入（對話）提供了值，使用它
   - 否則從現有倉庫上下文推斷（README、文件、之前嵌入的章程版本）
   - 對於治理日期：`RATIFICATION_DATE` 是原始批准日期（如果未知則詢問或標記 TODO），`LAST_AMENDED_DATE` 是修改時的今天日期，否則保留之前的值
   - `CONSTITUTION_VERSION` 必須遵循語意化版本規則遞增：
     * MAJOR（主版本）：向後不相容的治理/原則刪除或重新定義
     * MINOR（次版本）：新增原則/章節或實質性擴展的指導
     * PATCH（補丁）：澄清、措辭、錯別字修正、非語意改進
   - 如果版本升級類型不明確，在最終確定前提出理由

3. 起草更新後的章程內容：
   - 用具體文本替換每個佔位符（不留括號標記，除非專案有意保留的範本槽位—需明確說明理由）
   - 保留標題層級，替換後可以刪除註釋，除非它們仍能提供澄清指導
   - 確保每個原則章節包含：簡潔的名稱行、段落（或項目列表）描述不可協商的規則、明確的理由（如果不明顯）
   - 確保治理章節列出修訂程序、版本控制策略和合規審查期望

4. 一致性傳播檢查清單（將先前清單轉換為主動驗證）：
   - 讀取 `.specify/templates/plan-template.md` 並確保任何「章程檢查」或規則與更新後的原則一致
   - 讀取 `.specify/templates/spec-template.md` 進行範圍/需求對齊—如果章程添加/刪除了必填章節或约束則更新
   - 讀取 `.specify/templates/tasks-template.md` 並確保任務分類反映新增或刪除的原則驅動任務類型（例如可觀測性、版本控制、測試紀律）
   - 讀取 `.specify/templates/commands/*.md` 中的每個指令檔案（包括本檔案），驗證不再有過時的引用（如僅針對 CLAUDE 的代理特定名稱），當需要通用指導時
   - 讀取任何運行時指導文件（例如 `README.md`、`docs/quickstart.md` 或代理特定的指導檔案）。更新對已更改原則的引用

5. 產生同步影響報告（更新後作為 HTML 註釋添加到章程檔案頂部）：
   - 版本變更：舊版本 → 新版本
   - 已修改原則列表（如果重命名則為：舊標題 → 新標題）
   - 新增章節
   - 刪除章節
   - 需要更新的範本（✅ 已更新 / ⚠ 待處理）及檔案路徑
   - 如果有故意推遲的佔位符，記錄後續待辦事項

6. 最終輸出前的驗證：
   - 無剩餘未解釋的括號標記
   - 版本行與報告匹配
   - 日期採用 ISO 格式 YYYY-MM-DD
   - 原則是聲明性的、可測試的，不含模糊語言（"should" → 在適當時替換為 MUST/SHOULD 並說明理由）

7. 將完成的章程寫回 `.specify/memory/constitution.md`（覆蓋）

8. 向使用者輸出最終摘要，包含：
   - 新版本和升級理由
   - 任何標記為需要手動跟進的檔案
   - 建議的提交訊息（例如：`docs: amend constitution to vX.Y.Z (principle additions + governance update)`）

格式和樣式要求：
- 完全按照範本中的 Markdown 標題使用（不降級/升級標題級別）
- 長理由行要換行以保持可讀性（理想情況下 <100 字元），但不要強制執行以避免不自然的斷行
- 章節間保持一個空行
- 避免尾隨空格

如果使用者提供部分更新（例如僅修訂一個原則），仍需執行驗證和版本決策步驟。

如果關鍵資訊缺失（例如批准日期確實未知），插入 `TODO(<FIELD_NAME>): explanation` 並在同步影響報告的推遲項目中記錄。

不要建立新範本；始終操作現有的 `.specify/memory/constitution.md` 檔案。
